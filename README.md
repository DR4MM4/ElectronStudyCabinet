# Электронный учебный кабинет преподавателя и студента

Учебный проект на ASP.NET Core MVC / C# / PostgreSQL для индивидуального практического задания.

## Возможности
- Регистрация студентов и вход с использованием ASP.NET Core Identity (пароли хранятся в виде безопасных хешей).
- Роли `Teacher` и `Student`, защита маршрутов на сервере.
- Управление дисциплинами и темами, создание лекций, добавление текстовой теории и файлов PDF/DOC/DOCX/TXT.
- Контрольные вопросы с автоматической проверкой текстового ответа.
- Тесты с тремя вариантами ответа, автоматический подсчёт результата, проходной порог 70%, сохранение попыток.
- Сохранение индивидуального прогресса студента.
- Последовательное открытие лекций. Сервер проверяет прохождение предыдущей лекции, поэтому нельзя обойти блокировку прямым URL.
- Панель результатов преподавателя и ручное открытие лекции для студента.
- Начальные демонстрационные данные и учётные записи.

## Требования
- .NET 10 SDK
- PostgreSQL 14 или новее
- Visual Studio 2022 (ASP.NET and web development) либо VS Code

## Быстрый запуск
1. Установите PostgreSQL и создайте базу:
   ```sql
   CREATE DATABASE electronic_cabinet;
   ```
2. Откройте `appsettings.json` и измените `Username` и `Password` в `DefaultConnection`.
3. В терминале из каталога проекта выполните:
   ```bash
   dotnet restore
   dotnet run
   ```
4. Откройте URL, показанный в терминале.

При первом запуске приложение создаёт таблицы и демо-данные. Для учебного запуска используется `EnsureCreated`. Перед промышленным развёртыванием следует перейти на EF Core Migrations и настроить резервное копирование.

## Демо-учётные записи
- Преподаватель: `teacher` / `Teacher123!`
- Студент: `student` / `Student123!`

После демонстрации смените пароли и не используйте демонстрационные учётные данные в открытой сети. Регистрация через интерфейс создаёт роль студента; назначать преподавателей следует только администратору.

## Проверка основной логики
1. Войдите как `student`.
2. Откройте «Мои дисциплины» и первую лекцию.
3. Ответьте на контрольный вопрос и пройдите тест минимум на 70%.
4. Вернитесь к списку дисциплин: вторая лекция станет доступна.
5. Попробуйте открыть вторую лекцию до прохождения первой в новой учётной записи: сервер должен перенаправить к списку дисциплин.
6. Войдите как `teacher`, добавьте дисциплину, тему, лекцию, контрольный вопрос и тестовый вопрос.
7. Откройте результаты тестирования и проверьте историю попыток.

## Структура
- `Controllers` — маршруты и бизнес-логика.
- `Models` — сущности базы данных.
- `Data` — контекст EF Core и начальная инициализация.
- `ViewModels` — модели форм.
- `Views` — Razor-страницы.
- `wwwroot/css/site.css` — оформление интерфейса.
- `wwwroot/uploads` — загружаемые учебные материалы.

## Важные замечания
- В учебной версии проходной балл фиксирован на уровне 70%.
- Контрольный вопрос поддерживает короткий текстовый ответ; развёрнутые ответы с ручной проверкой, таймер теста, ограничение количества попыток и отчёты по группам пока не реализованы.
- Для доступа по локальной сети настройте Kestrel/IIS, firewall и HTTPS. Не открывайте PostgreSQL для прямого доступа студентов.
- Не храните секреты базы данных в публичном репозитории. Для реального развёртывания используйте переменные окружения или Secret Manager.
- Для производственного использования добавьте миграции EF Core, проверку размера загружаемых файлов, антивирусную проверку и резервное копирование базы и каталога `wwwroot/uploads`.
