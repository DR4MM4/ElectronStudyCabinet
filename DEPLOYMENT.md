# Инструкция по запуску и внедрению

## 1. Подготовка
1. Установить .NET 10 SDK и PostgreSQL.
2. В PostgreSQL создать пользователя приложения с паролем и базу `electronic_cabinet`.
3. Открыть `appsettings.json` и указать правильные `Username` и `Password`.
4. Не публиковать реальные пароли в Git.

Пример SQL (выполняется администратором PostgreSQL):
```sql
CREATE USER cabinet_user WITH PASSWORD 'replace-with-a-strong-password';
CREATE DATABASE electronic_cabinet OWNER cabinet_user;
```
В строке подключения указать `Username=cabinet_user;Password=...`.

## 2. Запуск из Visual Studio
1. Распаковать проект.
2. Открыть `ElectronStudyCabinet.csproj`.
3. Дождаться восстановления NuGet-пакетов.
4. Указать пароль базы данных в `appsettings.json`.
5. Запустить проект клавишей F5 или Ctrl+F5.
6. Открыть адрес, который показан в браузере.

Первый запуск создаёт таблицы и демонстрационные учётные записи. Для учебного прототипа используется `EnsureCreated`; это удобно для пустой базы. При изменении моделей и для дальнейшего сопровождения следует перейти на EF Core Migrations.

## 3. Демонстрационные пользователи
- Преподаватель: `teacher` / `Teacher123!`
- Студент: `student` / `Student123!`

Пароли демонстрационные. Сменить их перед эксплуатацией. Не выдавать роль Teacher обычным студентам.

## 4. Проверка сценария студента
1. Войти как `student`.
2. Открыть первую лекцию в демонстрационной дисциплине.
3. Ответить `тестирование` на контрольный вопрос.
4. Правильно ответить на тестовые вопросы, чтобы получить не менее 70%.
5. Вернуться к дисциплине и убедиться, что следующая лекция стала доступна.
6. Проверить, что повторный вход не удаляет прогресс.
7. Попробовать открыть URL следующей лекции до завершения предыдущей в новой учётной записи.

## 5. Проверка сценария преподавателя
1. Войти как `teacher`.
2. Создать дисциплину.
3. Добавить тему.
4. Добавить лекцию с текстом и при необходимости PDF/DOCX/TXT.
5. Добавить контрольный вопрос и тестовый вопрос.
6. Открыть результаты тестирования и проверить попытки.
7. При необходимости вручную отметить лекцию пройденной для выбранного студента.

## 6. Публикация на компьютере преподавателя
В терминале из каталога проекта:
```bash
dotnet restore
dotnet publish -c Release -o publish
```
На компьютере преподавателя должны быть установлен .NET 10 ASP.NET Core Runtime (если приложение запускается как framework-dependent) и доступная база PostgreSQL. Перенесите содержимое `publish`, настройте строку подключения через переменную окружения `ConnectionStrings__DefaultConnection` и запускайте:
```bash
dotnet ElectronStudyCabinet.dll
```
Для постоянной работы настройте запуск приложения как службу/задачу планировщика либо разместите за IIS. Для сетевого доступа настройте Kestrel/IIS, firewall и HTTPS. PostgreSQL не должен быть доступен клиентским компьютерам напрямую.

## 7. Резервное копирование
Резервировать нужно и базу данных, и каталог `wwwroot/uploads`.
Пример создания дампа:
```bash
pg_dump -Fc -U cabinet_user -d electronic_cabinet -f electronic_cabinet.backup
```
Пример восстановления в заранее созданную пустую базу:
```bash
pg_restore -U cabinet_user -d electronic_cabinet electronic_cabinet.backup
```
Храните копии отдельно от компьютера преподавателя и регулярно проверяйте восстановление.

## 8. Известные ограничения учебной версии
- Проходной балл фиксирован на уровне 70%.
- Контрольные вопросы поддерживают короткий текстовый ответ с автоматической проверкой.
- Тест поддерживает выбор одного варианта из трёх.
- Не реализованы таймер теста, лимит попыток, ручная проверка развёрнутых ответов, группы студентов и отчёты в CSV/PDF.
- Файлы загружаются в локальную папку проекта; для реальной эксплуатации добавьте ограничение размера, проверку содержимого файлов и резервирование.
- Для производственного запуска необходимы миграции, HTTPS, секреты через переменные окружения/Secret Manager, политика обновления и журналирование административных действий.
