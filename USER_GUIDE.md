# Краткая инструкция пользователя

## Студент
1. Откройте адрес приложения в браузере и войдите под своей учётной записью. Если аккаунта нет, зарегистрируйтесь.
2. В личном кабинете выберите дисциплину и первую доступную лекцию.
3. Изучите текст теории или откройте прикреплённый материал.
4. Ответьте на контрольные вопросы и пройдите тест.
5. Если результат недостаточный, повторите материал и попробуйте снова. Следующая лекция откроется только после выполнения обязательных условий.
6. Прогресс и попытки хранятся в базе и остаются после выхода из системы.

## Преподаватель
1. Войдите с учётной записью преподавателя.
2. Создайте дисциплину, затем тему и лекции в нужном порядке.
3. Для каждой лекции добавьте теоретический текст/файл, контрольные вопросы и вопросы теста.
4. Используйте панель результатов для контроля попыток и прогресса студентов.
5. Ручную разблокировку применяйте только при обоснованной необходимости.

## Учётные записи и безопасность
- Демонстрационные данные: `teacher` / `Teacher123!` и `student` / `Student123!`.
- Замените демонстрационные пароли до сетевого использования.
- Регистрация создаёт студента. Не выдавайте роль преподавателя через обычную регистрацию.
- Не открывайте порт PostgreSQL для ученических компьютеров: браузеры должны обращаться только к веб-приложению.
